### 3. 🎯 Продвинутый промпт-инжиниринг

#### Автоматическое улучшение запросов

**Без оптимизации:**
```
User: как работает нейронка
```

**С оптимизацией:**
```
User: как работает нейронка

Prompt Engineer:
→ Определяет тип: explanation
→ Добавляет контекст пользователя
→ Оптимизирует системный промпт
→ Добавляет структуру ответа

Результат: Подробный, структурированный ответ с примерами
```

#### Персонализация

```python
system_prompt = prompt_engineer.get_system_prompt(
    model_type='gpt',
    mode='coding',
    user_context={
        'name': 'Иван',
        'expertise': 'junior',
        'preferences': {'detailed': True, 'examples': True}
    }
)
```

**Результат:** Ответы адаптированы под уровень пользователя
