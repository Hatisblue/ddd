# 🤖 Продвинутый AI Телеграм-бот

Многофункциональный телеграм-бот с интеграцией передовых AI-моделей: GPT-4o, Gemini 1.5, Grok и генерацией изображений через DALL-E 3.

## ✨ Возможности

### 🎯 Основной функционал
- **Множество AI-моделей**: GPT-4o, GPT-4 Turbo, o1-preview, Gemini 1.5 Pro/Flash, Grok
- **Генерация изображений**: DALL-E 3 и DALL-E 2
- **Голосовые сообщения**: Транскрипция через Whisper API
- **История диалогов**: Контекстные беседы с сохранением истории
- **Экспорт чатов**: Выгрузка истории в JSON/CSV

### 💎 Продвинутые функции
- **Админ-панель**: Управление пользователями, лимитами токенов, правами
- **Статистика**: Детальная аналитика использования по пользователям и моделям
- **Реферальная система**: Бонусы за приглашение друзей
- **Промокоды**: Гибкая система промо-акций
- **Премиум-подписки**: Расширенные возможности для премиум-пользователей

### 💳 Платежные системы
- **Telegram Stars**: Встроенная платежная система Telegram
- **ЮКасса**: Оплата картами для пользователей из РФ
- **Пакеты токенов**: От 50K до 1M токенов

### 🎨 Режимы работы
- **Обычный**: Стандартный режим общения
- **Креативный**: Более творческие ответы
- **Деловой**: Формальный стиль общения

- **Продвинутый Rate Limiting**: С прогрессивными наказаниями
- **AI-powered антиспам**: Интеллектуальная детекция спама
- **Мониторинг безопасности**: Real-time отслеживание угроз
- **Автоблокировка атак**: Автоматическая защита от злоупотреблений

### ⚡ Оптимизация и производительность
- **Умное кэширование**: Экономия 20-30% токенов
- **Prompt Engineering**: Автоматическое улучшение запросов

## 🚀 Быстрый старт

### Требования
- Python 3.10+
- PostgreSQL (или SQLite для разработки)
- Redis (опционально, для кэширования)

### Установка

1. **Клонировать репозиторий**
```bash
git clone <repository-url>
cd ddd
```

2. **Создать виртуальное окружение**
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

3. **Установить зависимости**
```bash
pip install -r requirements.txt
```

4. **Настроить переменные окружения**
```bash
cp .env.example .env
# Отредактируйте .env и добавьте свои API ключи
```

5. **Запустить бота**
```bash
python -m bot.main
```

## 🎯 Использование

### Основные команды

- `/start` - Начать работу с ботом
- `/help` - Справка
- `/balance` - Проверить баланс токенов
- `/models` - Выбрать AI модель
- `/image` - Генерировать изображение
- `/stats` - Статистика использования
- `/settings` - Настройки
- `/referral` - Реферальная программа
- `/promo` - Активировать промокод

### Админ команды

- `/admin` - Админ-панель
- `/users` - Список пользователей
- `/broadcast <текст>` - Рассылка всем пользователям

## 🔑 Получение API ключей

### OpenAI (GPT)
1. Зарегистрируйтесь на [platform.openai.com](https://platform.openai.com)
2. Перейдите в раздел API Keys
3. Создайте новый ключ

### Google AI (Gemini)
1. Перейдите на [ai.google.dev](https://ai.google.dev)
2. Получите API ключ

### xAI (Grok)
1. Зарегистрируйтесь на [x.ai](https://x.ai)
2. Получите доступ к API

### ЮКасса
1. Зарегистрируйтесь на [yookassa.ru](https://yookassa.ru)
2. Получите Shop ID и Secret Key в личном кабинете

## 💡 Советы по использованию

### Оптимизация расходов
- Используйте **GPT-4o mini** для большинства запросов (дешевле)
- **Gemini 1.5 Flash** - отличная альтернатива для быстрых ответов
- **o1-preview/mini** - для сложных задач, требующих глубокого рассуждения

### Генерация изображений
- DALL-E 3: лучшее качество, но дороже
- DALL-E 2: быстрее и дешевле

### Безопасность
- Храните API ключи в безопасности
- Используйте `.env` для конфиденциальных данных
- Регулярно обновляйте зависимости

## 🛠 Разработка

### Добавление новой AI модели

1. Создайте клиент в `bot/ai/`
2. Добавьте модель в `AIModel` enum в `models.py`
3. Интегрируйте в `chat.py`
4. Обновите клавиатуры в `keyboards.py`

### Добавление новой команды

1. Создайте обработчик в соответствующем файле handlers/
2. Зарегистрируйте в `main.py`
3. Добавьте в справку (`/help`)
